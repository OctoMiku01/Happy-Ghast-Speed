# Happy Ghast Speed

> [!WARNING]
> **AI disclaimer:** The code of this mod was written by AI (Claude, by Anthropic). The author directs what it does
> and tests it in game, but does not review the code itself. Please report problems as an issue.
>
> This mod is mainly made for private use. You are welcome to try it, but it comes without any promise of support.

Happy Ghasts fly faster while a player rides them, and drift around slower when nobody does. Minecraft 26.3 and
26.2, Fabric.

| | Flying speed | Ridden top speed |
|---|---|---|
| Vanilla | 0.05 | about 3.6 blocks/s |
| Ridden | 0.08 | about 9.2 blocks/s |
| Without a rider | 0.03 | |

The speed is a temporary attribute modifier that is never saved. If you remove the mod, every Happy Ghast flies at
its normal speed again. Ghasts whose base speed was changed by another pack still end up at the speeds above.

## Installation

Needs [Fabric Loader](https://fabricmc.net/). Download the jar for your Minecraft version from the
[releases](https://github.com/OctoMiku01/Happy-Ghast-Speed/releases) and put it into the `mods` folder. On a server
it is enough to install it on the server.
